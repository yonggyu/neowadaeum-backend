# 세이프티 오탐 급증

> **막는 쪽으로 틀리는 것이 설계다.** 그래서 오탐은 장애처럼 보이지 않고 **조용히 쌓인다.**

## 징후

| 지표 | 무엇을 본다 |
|---|---|
| `safety.judgement{level,outcome=blocked}` | 레벨별 차단 비율이 뛴다 |
| `safety.blocked.category{level,category}` | **어느 카테고리가 늘었는가** — 여기가 출발점이다 |
| `play.turn.outcome` | 차단으로 끝난 턴이 늘어난다 |
| `ai.call{purpose=safety, outcome=...}` | 판정 호출 자체가 실패하고 있는가 |

사용자에게 보이는 모습 — 턴이 차단 응답으로 끝난다. **차단 사유는 전달되지 않는다** (R9.6) —
어떤 표현이 걸렸는지 알려주면 우회 학습을 돕기 때문이다. 그래서 사용자 문의만으로는 원인을 못 찾는다.
**지표와 내부 기록에서 찾아야 한다.**

## 먼저 갈라야 할 두 가지

**1. 판정이 실패하고 있는가, 판정이 막고 있는가.**

`ai.call{purpose=safety}` 의 실패율을 본다.

- **실패율이 높다** → 이것은 오탐이 아니라 **Provider 장애**다. 판정 실패는 통과가 아니라 차단이므로
  (fail-closed, I-12) 모든 턴이 막힌 것처럼 보인다. → [Provider 장애](provider-outage.md) 로 간다.
- **실패율이 정상인데 차단이 늘었다** → 진짜 판정 변화다. 2번으로.

**2. 어느 레벨인가** (`safety.judgement` 의 `level` 태그).

| 레벨 | 무엇이 바뀌면 여기가 움직이는가 |
|---|---|
| L0 (입력) | 블록리스트 갱신 · UGC 유입 변화 |
| L1 (관리자 자유입력) | 관리자 콘솔 사용 (I-17 — 무검열 통로는 없다) |
| L2 (AI 출력) | 판정 모델·프롬프트 변경, 작품 성격 변화 |
| L3 (샘플링) | 샘플링 비율 변경 |

**레벨을 먼저 특정하지 않으면 엉뚱한 스위치를 만진다.**

## 조치

### 블록리스트가 원인일 때 (L0)

관리자 API 로 항목을 확인·수정한다.

```
GET    /api/v1/admin/blocklist
DELETE /api/v1/admin/blocklist/{entryId}
```

- 관리자 경로는 **역할 · IP · 2FA 셋을 모두** 요구한다 (S-4). 장애 중이라고 셋 중 하나를 열지 않는다.
- **대조는 정규화된 값으로 한다.** 원문이 달라 보여도 같은 항목에 걸릴 수 있다.
- 항목을 지우면 **이미 내려간 작품은 자동으로 올라오지 않는다.** 재스캔 배치가 다시 판정한다 (B-59).
  자동으로 내린 것을 자동으로 올리면 판정이 왕복한다.

### 샘플링·임계값이 원인일 때 (L3 · 자동 정지)

값은 코드가 아니라 `service_config` 에 있다 — **배포 없이 바꾼다.**

| 키 | 무엇을 정하는가 |
|---|---|
| `ugc.review.sampling_rate` | 승인작 사후 샘플링 비율 (B-59) |
| `ugc.report.suspend_threshold` | 신고 누적 자동 정지 (B-57) |

**샘플링은 정지시키지 않는다.** 뽑히는 것과 내려가는 것은 다르다 — 뽑힌 작품은 검수 큐에 올라가고
사람이 판정한다.

### 판정 모델이 원인일 때 (L2)

`ai.providers.<이름>.models.safety` 를 확인한다. **생성 모델과 같은 값이어도 되지만, 그것은 설정의
선택이지 구조가 강요하는 것이 아니다** (I-12 — L2 는 생성 모델과 별개 판정기다).

모델을 바꿨다면 **바꾸기 전 구간과 후 구간의 `safety.blocked.category` 분포를 비교한다.**
카테고리 한두 개만 튀었다면 판정 성향의 변화이고, 전면적으로 올랐다면 프롬프트·스키마 쪽이다.

## 하지 말아야 할 것

- **세이프티를 끄지 않는다.** L2 는 provider 와 무관하게 **항상 서버에서** 돈다 (I-13). 무검열 로컬
  모델을 붙여도 15세 등급이 유지되는 것이 그 요건이며, 끄는 스위치는 만들지 않는다.
- **차단 사유를 사용자에게 노출하지 않는다** (R9.6). 문의 대응에서도 마찬가지다.
- **블록리스트 실제 항목을 이슈·PR·커밋에 적지 않는다** (S-11). 그것은 그대로 우회 목록이 된다.
- **임계값과 샘플링 비율을 공개 채널에 적지 않는다** (§13-12). 값을 알면 그 아래로 관리할 수 있다.
- **막힌 턴을 관리자 자유입력으로 대신 채우지 않는다.** 그것도 L1 을 거치며 (I-17), 사용자 소유
  세션에는 애초에 자유입력이 금지다 (I-18).

## 사후

- 오탐으로 확인된 건은 **재현 조건을 내부 기록으로만** 남긴다.
- 판정 원문은 `ai_call_log` 에 있다 (보관 90일). 읽는 경로는 감사 기록을 남긴다 (R12.3).
