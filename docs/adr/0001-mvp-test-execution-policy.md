# ADR-0001: MVP 기간의 테스트 실행 정책

> **분리는 검증 축소가 아니다.** 이 문서가 하는 일은 §10.1 의 필수 테스트 14종이 *언제* 도는지를 정하는 것뿐이다. **어떤 항목도 삭제하지 않으며, 어떤 항목도 "안 돌린다"가 되지 않는다.**

## 상태

제안

## 맥락

`CLAUDE.md` §10.1 은 머지 불가 조건으로 필수 테스트 14종을 정한다. **언제** 도는지는 정하지 않았고, 현재는 "PR 마다 전부"가 암묵 기본값이다.

B-05(#19)에서 개발 루프 속도를 실측했다. 표의 수치는 전부 `n=5`, 실행 순서 무작위, **중앙값**이다.

| 측정 | `/mnt/c` (WSL2 9p) | WSL 네이티브 (ext4) |
|---|---|---|
| `./gradlew test` (`--rerun`) | 16.8s | **3.0s** |
| `./gradlew integrationTest` | 35.9s | **8.8s** |
| Spring 컨텍스트 기동 (1벌) | 27.8s | **6.2s** |

두 가지가 드러났다.

1. **가장 큰 비용은 테스트의 수가 아니라 컨텍스트 기동이라는 고정 비용이다.** 컨테이너 3개(Ryuk·Redis·Postgres) 기동 합계는 2.5초로 전체의 3분의 1도 안 된다.
2. **엔티티가 사실상 0개인 상태에서 이 숫자가 나온다.** B-07 ~ B-11 로 엔티티가, B-32 로 통합 테스트가 붙으면 단조 증가한다.

§10.1 의 14종 중 일부(멱등성·낙관적 잠금·버전 고정)는 본질적으로 인프라와 동시성을 요구한다. **지금은 해당 코드가 없어 비용이 0이지만, 생기는 순간 PR 마다 붙는다.** 그 시점에 결정하면 급할 때의 판단이 되고, 급할 때의 선택은 "테스트를 빼는" 쪽이다.

§8.9 가 이 결정의 무게를 정한다. 1인 개발에서 승인 리뷰의 자리를 CI 가 메운다. **CI 가 느려지면 대체 장치가 약해진다** — 규칙으로는 "전부 PR 필수"가 깔끔하지만, 지키기 어려워지는 순간 지켜지지 않는다.

## 결정

§10.1 의 14종을 **실행 시점**으로 3분류한다. 항목은 하나도 삭제하지 않는다.

### 로컬 + PR 필수 (8종)

| §10.1 | 항목 | 근거 |
|---|---|---|
| 1 | 결정론 (I-15) | 전부 순수 함수다. 인프라도 컨테이너도 필요 없다. |
| 2 | clamp (R4.2) | 합쳐 1초 미만이라 뺄 이유가 없다. |
| 3 | 화이트리스트 (R4.1) | |
| 4 | AI 필드 잠금 (I-9) | |
| 5 | 페이로드 유출 (I-3) | |
| 6 | 프롬프트 오버라이드 (I-7) | |
| 11 | 기본 엔딩 (R2.2, R7.7) | |
| 13 | 연령 게이트 (R10.2) | |

### CI nightly (3종)

| §10.1 | 항목 | 강등 근거 | 승격 시점 |
|---|---|---|---|
| 7 | 멱등성 (R6.2) | 인프라(Redis)와 동시성이 필요해 비싸다. 보호 대상은 **중복 과금**인데, 유저 0명 · 실트래픽 0 동안 손실이 0이다. | **B-33** PR |
| 8 | 낙관적 잠금 (I-6) | 동시 요청을 실제로 만들어야 한다. 보호 대상은 **데이터 무결성**이며, 위와 같은 이유로 지금 손실이 0이다. | **B-33** PR |
| 12 | 버전 고정 (R2.1, R8.8) | 버전 발행 경로 전체가 필요하다. UGC 가 없는 동안 새 버전을 발행하는 주체가 없다. | **B-56** PR |

**승격은 경로 기반으로 자동화한다.** 위 작업의 PR 이 해당 코드를 건드리면 그 PR 에서 `@Tag("nightly")` 를 떼고 PR 필수로 올린다. 이 표의 "승격 시점" 열이 그 근거다.

### 미도래 (3종)

| §10.1 | 항목 | 대상 작업 |
|---|---|---|
| 9 | 타임아웃 (R6.4) | B-32 |
| 10 | 세이프티 차단 (R9.2) | B-30 |
| 14 | UGC 노출 (I-8) | B-54 |

대상 코드가 없어 지금 분류할 수 없다. **생기는 시점에 이 ADR 을 갱신한다.**

### 절대 강등하지 않는 것

**§10.1-10 (세이프티 차단)과 §10.1-14 (UGC 노출)는 어떤 경우에도 nightly 로 내리지 않는다.**

- 세이프티 이슈는 무조건 P0 이며 인원수와 무관하게 완화 대상이 아니다(§8.9 "절대 완화하지 않는 것").
- I-8 위반(`pending`/`rejected`/`private` 작품이 타인에게 노출)은 **되돌릴 수 없다.**
- 이 레포는 공개다(S-11). 이 ADR 은 **"무엇을 PR 마다 안 돌리는지"를 그대로 공개한다.** 그 목록에 세이프티가 들어가 있는 것은 그 자체로 안전하지 않다.

## 결과 (되돌리기 비용 포함)

### 이 결정이 지금 시간을 벌지 않는다

7 · 8 · 12 는 **아직 코드가 없다.** 이 ADR 을 적용해도 오늘의 CI 는 1초도 빨라지지 않는다. 목적은 **비싼 테스트가 생겼을 때 자동으로 nightly 로 가도록 미리 정해 두는 것**이다. 실제 속도 개선은 별도다(아래 "함께 한 것").

### 되돌리기 비용: 낮음

태그 한 줄을 떼면 그 테스트는 즉시 PR 필수로 돌아온다. 스키마도 데이터도 움직이지 않는다.

### 복귀 조건 (강제)

**실사용자 트래픽이 유입되는 시점에 7 · 8 · 12 를 무조건 PR 필수로 되돌린다.**

강등 근거가 전부 "유저 0명이라 손실이 0"이기 때문이다. 그 전제가 사라지면 근거도 사라진다. 중복 과금과 데이터 무결성은 사용자가 있는 순간부터 되돌릴 수 없는 손해가 된다. 이 조건은 M3(오픈 가능) 체크리스트에 포함한다.

### nightly 가 방치되면 이 결정은 검증 축소가 된다

아무도 안 보는 nightly 는 없는 것과 같다. 그래서 `nightly.yml` 은 실패 시 `bug` 라벨 이슈를 자동 생성한다. 같은 제목의 열린 이슈가 있으면 코멘트만 붙인다 — 매일 새 이슈가 쌓이면 그것도 안 보게 된다.

**nightly 실패를 방치한 채로 머지하지 않는다.** 이 문장이 지켜지지 않으면 위 분류는 무효다.

### 9p 가설 — 검증하고 채택

이 ADR 을 쓰게 만든 속도 문제의 **주원인은 테스트 구성이 아니라 레포 위치였다.**

레포를 WSL 네이티브 경로에 클론해 같은 방식(`n=5`, 순서 무작위, 중앙값)으로 재측정한 결과다.

| | `/mnt/c` (9p) | ext4 | |
|---|---|---|---|
| `integrationTest` | 35.9s | **8.8s** | **4.1배** |
| `test` (`--rerun`) | 16.8s | **3.0s** | 5.6배 |

분산은 양쪽 모두 ±0.2초 이내였다. **가설을 채택한다.** 따라서 레포를 WSL 네이티브 경로에 두는 것은 취향이 아니라 **온보딩 필수 절차**이며 `README.md` 에 그렇게 적었다.

이 사실은 위 분류를 무효화하지 않는다. 7 · 8 · 12 의 비용은 파일시스템이 아니라 인프라·동시성에서 오고, ext4 로 옮겨도 그대로 남는다.

## 함께 한 것 (이 ADR 의 결정은 아니다)

측정으로 효과가 확인되어 적용한 것과, 확인되지 않아 되돌린 것을 함께 남긴다. 기각된 실험도 결과다.

| 조치 | 전 | 후 | 채택 |
|---|---|---|---|
| `@Tag("container")` 분리 (B-05, `6084c72`) | `test` 38.2s | `test` 1.9s | O |
| WSL 네이티브 경로 | 35.9s | 8.8s | O (온보딩 절차) |
| `TESTCONTAINERS_RYUK_DISABLED=true` (로컬 한정) | 8.69s | 8.15s | O — 구간 미중첩. 단, **CI 에서는 켜 둔다** |
| Redis 컨테이너 제거 | 36.4 / 41.4s | 38.8 / 36.0s | **X — 차이가 분산 안. 되돌림** |
| `gradle.properties` 튜닝 | no-op 0.6s | — | **X — Gradle 설정은 병목이 아니었다** |
| Testcontainers reuse | — | — | **X — 컨테이너 기동 2.5초 중 일부라 이득 없음** |

컨텍스트 캐시 키가 갈라지는지도 확인했다. **1벌이었다**(`Starting ...Tests` 1회). 다만 클래스가 늘면 갈라지기 쉬우므로 `ContainerTestBase` 로 고정했다.
