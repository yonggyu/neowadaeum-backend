# safety — L0~L3 판정

> **S-11 — 이 레포는 공개다.** 이 파일과 코드 주석·테스트 이름에 **블록리스트 실제 항목, 정규화를 뚫는 표기 예시, 탐지 회피 수법을 적지 않는다.** 실제 문자열은 테스트 픽스처에만 둔다.

## 판정 계층

| | |
|---|---|
| **L0** | 입력 중 실시간 (UGC 드래프트, debounce 800ms). API 이름은 `precheck` |
| **L1** | 제출 시 (UGC 전체 + 관리자 자유입력). **관리자 자유입력도 예외가 아니다** (I-17) |
| **L2** | AI 응답 직후 (본문 + 선택지) |
| **L3** | 상시 (신고 · 랜덤 샘플링) |

## L2 — 깨면 안 되는 둘

- **생성 모델과 별개의 판정기로 수행한다** (I-12). 자기 검열에 의존하지 않는다.
- **provider와 무관하게 항상 서버에서 수행한다** (I-13). 무검열 로컬 모델을 붙여도 15세 등급이 유지되어야 한다.
- AI 응답은 L2 통과 전까지 사용자에게 도달하지 않는다 (I-2).
- 즉시차단 카테고리는 **재생성 없이** 즉시 `422 SAFETY_BLOCKED`. 그 외 blocked는 재생성 1회 후 여전히 blocked면 차단.
- **정책 순서는 차단 > 재생성 > 마스킹이다** (§13-46). 개인정보를 가렸다고 다른 사유가 사라지지 않는다.
- **마스킹은 1단(블록리스트)이 찾은 자리에만 붙는다.** 2단(의미 분류)은 카테고리만 돌려주므로 자리를 모른다 — 그때는 가리지 않고 재생성 1회 → 차단이다. **분류기 계약에 위치를 더하지 않는다** (§13-21).
- **L1 은 걸린 것이 곧 거부다.** 출력의 처리(재생성·마스킹)를 입력으로 가져오지 않는다 (§9.2 — UGC 입력은 차단).

## 차단 응답

- **`retry` 액션을 넣지 않는다.** 동일 입력 → 동일 결과 → 무한 루프다. `choose_other` / `leave`만.
- **차단 사유를 사용자에게 노출하지 않는다.** 카테고리도 알려주지 않는다 — 어떤 표현이 걸렸는지 알려주면 우회를 학습시킨다.
- 서버 내부(`turn.safety_verdict`, `ai_call_log.safety_flags`)에는 상세 사유를 남긴다.
- 세이프티 차단은 `WARN`, 동일 세션 3회 이상 반복 차단은 `ERROR` + 알람.

## 블록리스트

- **`blocklist_entry`는 authoring 소유다** (ADR-0002). safety는 `common/spi`의 조회 인터페이스로 **읽기만** 한다. `safety → authoring` 참조를 만들지 않는다.
- **SPI 구현 빈이 없으면 부팅 실패, 런타임 조회 실패는 차단(fail-closed).** 세이프티에서 fail-open은 장애가 곧 검수 우회다.
- 정규화기는 `common/support`에 있다. 공백 삽입형 · 숫자 치환형 · 자모 혼용형이 **동일 정규화 값으로 수렴**해야 한다.

## 이슈

세이프티 결함을 발견하면 **무조건 P0**이고 진행 중이던 작업을 멈추고 먼저 연다. 이슈 본문에 원문 대신 세션 ID · 턴 번호 · `ai_call_log` id로 지목한다.
